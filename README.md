# OIPSIP_Graphics-Design-Task-4-Infographic-
Infographic designed for Oipsip Task-4, titled Who Gets to Eat Well? Using 2024 global data, it presents seven statistics on hunger, food affordability, and child malnutrition, with regional breakdowns and a focused India section. Built with bar charts and progress bars in a green, orange palette. Designed in Figma with a clean, data-driven layout.
